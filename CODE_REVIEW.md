For Yanli

I think the site is easy to navigate for each individual use cases. The interface is clean and interesting. The couple of use cases for finding a sublet, finding a roommate and posting a sublet were all very clear on how to execute those tasks independent of one another. I liked how after creating a listing, the listing popped up very quickly and looked great.

If I was going to build this into a product that is highly usable and frictionless, I would look to find a way to clarify the linkage between the postings, the possible roommates, and the sublet options. 

I found myself asking a few different questions because the app name suggests 
this is a deal between a subletter and someone subletting:

 - Should I be looking for a roommate or is a roommate coming with the apartment with a room?
 - Do I need to find a roommate at all because images and provided information suggested that I was just renting a single room?

I think there is an interesting angle about how someone responsible for paying rent but who is leaving for some time would want to help find a compatible roommate for their existing roommates.

I also think this could be tied into a larger apartment rental experience because renting in the city is annoying with the broker fees and it is so expensive. When you are moving from somewhere else and you don't know anyone, but you need a roommate because of the expense, that is a definite use case. I haven't done that in a long time, but that is what my experience was like when I came to Boston. Of course there might be a great experience out there that already handles the renter space that I am unaware of. 

Great job overall, because your team checked all of the boxes for the project!
